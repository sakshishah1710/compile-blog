<h2>What changed</h2><p>GitHub has updated Copilot for JetBrains with new configuration options for default models and Model Context Protocol (MCP) server management. The update also includes improvements to diagnostics handling, chat navigation, and account control interfaces within the IDE.</p><h2>Why it matters</h2><p>Model selection and MCP server configuration previously required going outside the IDE or accepting defaults. These new controls give developers more agency over their AI assistant's behavior without context-switching. MCP support is particularly notable—it's an emerging protocol for connecting AI assistants to external data sources and tools, suggesting GitHub is positioning Copilot for more extensible workflows.</p><h2>What to check</h2><p>If you're using JetBrains IDEs with Copilot, update to the latest plugin version to access the new settings. Look for model selection options in Copilot preferences and explore MCP server configuration if you're working with custom context sources. The improved diagnostics UI should make it easier to understand and fix issues when Copilot suggestions fall short or fail entirely.</p>
