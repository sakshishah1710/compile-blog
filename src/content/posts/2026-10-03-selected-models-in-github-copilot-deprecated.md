<h2>What Changed</h2><p>GitHub announced the deprecation of several AI models from GitHub Copilot as of October 2, 2026. The removals affect all Copilot interfaces: chat windows, inline code edits, ask and agent modes, and code completions. Users will no longer be able to select these deprecated models when working with Copilot.</p><h2>Why This Matters</h2><p>Model consolidation in developer tools typically signals a shift toward standardization or performance optimization. Teams relying on specific model behaviors for their workflows may need to adjust. However, GitHub has not disclosed which models were removed or their usage levels, making it difficult to assess immediate impact. The change affects enterprise and individual users alike, since it spans the entire Copilot product line.</p><h2>What To Do</h2><p>Check your Copilot settings to verify which model you're currently using. If you were using a deprecated model, test the available alternatives with your typical coding tasks to ensure they meet your needs. For teams with documented AI assistance workflows, update internal documentation to reflect the current model options. GitHub's support channels should have details on which specific models were affected if you need to file feedback about removed functionality.</p>
