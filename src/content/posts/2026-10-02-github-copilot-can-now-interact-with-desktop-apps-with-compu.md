<h2>What changed</h2><p>GitHub has launched "computer use" capabilities for Copilot in public preview. The feature allows Copilot to directly interact with desktop applications running on your machine, available through both the GitHub Copilot CLI and the native Copilot app on macOS and Windows. Instead of just generating code or answering questions, Copilot can now manipulate UI elements and execute actions in third-party desktop software.</p><h2>What this enables</h2><p>This moves Copilot beyond text generation into automation territory. You could theoretically ask Copilot to perform multi-step workflows that span your IDE, terminal, and other desktop tools. The preview status signals GitHub is testing how far developers want AI assistants to reach into their local environment—a capability with obvious productivity potential and equally obvious security implications.</p><h2>The practical angle</h2><p>Before enabling this, understand what you're granting access to. Review the permissions model and consider starting with the CLI version for more controlled interactions. This is computer automation, not just code completion—treat the security boundary accordingly. If your workflow involves sensitive data or production systems, wait for the preview period to surface edge cases before broad adoption.</p>
