<h2>What changed</h2><p>GitHub Mobile shipped an update with native support for iPhone Duo, Apple's foldable device. The app now adapts its interface when you unfold the screen, switching to a vertical tab layout that surfaces Copilot, Pull Requests, Issues, and Notifications as dedicated navigation areas.</p><h2>Why this matters for mobile workflows</h2><p>If you're reviewing PRs or triaging issues on a foldable, the extra screen real estate matters—but only if apps actually use it. GitHub's implementation means you're not just looking at a stretched phone UI. The vertical tabs are optimized for thumb reach on the wider unfolded screen, keeping core workflows accessible without awkward stretching or mode-switching.</p><h2>What it doesn't change</h2><p>This is a layout adaptation, not a feature expansion. You're still working within the existing GitHub Mobile feature set—no desktop-class diff views or multi-pane layouts yet. The update targets ergonomics on foldables, not parity with the web interface.</p><h2>Takeaway</h2><p>If you're using an iPhone Duo for on-call rotations or mobile code review, update the app. The adaptive layout makes navigation faster on the unfolded screen. For everyone else, this signals GitHub is tracking emerging form factors—expect similar treatment if you're on Android foldables.</p>
