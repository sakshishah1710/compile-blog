<h2>What changed</h2><p>GitHub Copilot's JetBrains extension now includes configuration options for default AI models and Model Context Protocol (MCP) server settings. The update also introduces improved diagnostics tooling and refined chat interface controls, including better account management within the IDE.</p><h2>Why it matters</h2><p>MCP server configuration in-IDE means teams can connect Copilot to internal context sources without leaving their workflow. Model selection at the IDE level gives developers control over which AI they're working with for different projects—useful when balancing cost, speed, or capability requirements. The diagnostics improvements should make troubleshooting Copilot behavior faster when things don't work as expected.</p><h2>What to check</h2><p>If you're using JetBrains IDEs with Copilot, update the extension to access the new settings panel. Look for model selection under Copilot preferences and MCP server configuration if your team runs internal context servers. The account controls consolidate switching between different Copilot subscriptions or organizations without plugin reinstalls.</p>
