<h2>What's changing</h2><p>GitHub announced it will deprecate specific models across all Copilot experiences on December 14, 2026. The deprecation affects every integration point: Copilot Chat, inline code edits, ask mode, agent modes, and standard code completions.</p><h2>Why this matters (and what it doesn't mean)</h2><p>Model deprecations are routine as providers rotate in newer versions with better performance or cost characteristics. The GitHub Changelog entry doesn't specify which models are being removed, but the company is giving teams advance notice to prepare. This isn't about Copilot going away—it's about the underlying model roster being trimmed.</p><h2>What to do</h2><p>Check the full GitHub Changelog post for the specific model list if you've explicitly configured model preferences in your Copilot settings. Most users won't need to take action since Copilot typically defaults to recommended models. If your team has workflows or scripts tied to specific model names via API, verify those references before December 14.</p>
