<h2>What's changing</h2><p>GitHub will deprecate selected models across all Copilot experiences on December 14, 2026. The deprecation affects Copilot Chat, inline edits, ask and agent modes, and code completions. The announcement was made in November 2025, providing users with approximately 13 months of advance notice.</p><h2>Why the long runway matters</h2><p>The extended deprecation timeline suggests these models aren't heavily used or have already been superseded by newer alternatives. GitHub is giving organizations substantial time to adjust workflows, update integrations, and test replacements. This isn't an emergency migration—it's planned obsolescence of older model versions.</p><h2>What to do now</h2><p>If you're using Copilot in any capacity, monitor GitHub's changelog for the specific model names being deprecated (not detailed in the initial announcement). Review your team's Copilot usage patterns and confirm you're not locked into specific model versions via API integrations or internal tooling. Most users relying on default model selection won't need to take action.</p>
