<h2>What's new</h2><p>Amazon Managed Grafana now supports creating workspaces running Grafana 13.2, bringing three years of upstream features into the managed service. The headline addition is Git Sync, which lets you link a workspace directly to a Git repository for dashboard management. Dynamic dashboards and PromQL query support in the CloudWatch data source plugin round out the release.</p><h2>Git Sync matters for teams managing dashboards at scale</h2><p>Git Sync treats dashboards as code—changes committed to your repository automatically propagate to Grafana workspaces. This solves the long-standing problem of dashboard drift across environments and makes peer review standard practice. For teams already managing infrastructure as code, this brings monitoring configs into the same workflow. The CloudWatch PromQL support is less transformative but welcome: it lets you query CloudWatch metrics using Prometheus syntax if your team is already fluent in PromQL.</p><h2>What it doesn't change</h2><p>This is for new workspaces only—existing deployments stay on their current version unless you migrate. Git Sync requires your team to maintain dashboard definitions in Git, which adds overhead if you're used to point-and-click editing. And while dynamic dashboards are included, the release notes don't detail what that means in practice beyond the feature name.</p><h2>Practical takeaway</h2><p>If you're spinning up new Managed Grafana workspaces and already use Git for Terraform or Kubernetes configs, enable Git Sync from day one. It prevents the dashboard sprawl that makes monitoring brittle as teams grow. For existing workspaces, evaluate migration effort against your dashboard change velocity—high-churn environments benefit most.</p>
