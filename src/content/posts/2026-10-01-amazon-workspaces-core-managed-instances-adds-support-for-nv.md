<h2>What changed</h2><p>AWS WorkSpaces Core Managed Instances now supports Graphics G7 instances, built on NVIDIA RTX PRO 4500 Blackwell Server Edition GPUs paired with Intel Xeon 6 processors. AWS claims up to 2.1x performance improvement over the previous G6 generation for graphics-intensive applications.</p><h2>What this enables</h2><p>The G7 instances target professional workloads like CAD/CAM and 3D rendering that need GPU acceleration. WorkSpaces Core is AWS's IaaS-style virtual desktop service where you manage the OS and applications yourself, unlike the fully managed WorkSpaces offering. This is purely a hardware upgrade—the service model and management responsibilities haven't changed.</p><h2>Practical impact</h2><p>If you're running graphics workloads on WorkSpaces Core G6 instances, you now have a faster option. The 2.1x claim suggests meaningful render time reduction, but real-world gains depend on your specific applications and bottlenecks. Check regional availability before planning migrations—new instance types typically roll out gradually across AWS regions.</p>
