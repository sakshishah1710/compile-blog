<h2>What changed</h2><p>GitHub now lets Team plan customers start self-serve trials of GitHub Advanced Security (GHAS) directly from their organization's Overview or Billing pages. Previously, GHAS features like code scanning and secret protection were only available on Enterprise plans or required sales contact.</p><h2>What you get in the trial</h2><p>The trial includes access to GitHub Code Security (which encompasses code scanning and dependency review) and GitHub Secret Protection. This lets smaller teams evaluate automated vulnerability detection and credential leak prevention before committing to the additional per-committer cost that GHAS typically adds to a subscription.</p><h2>Why it matters</h2><p>For teams on the $4/user/month tier, this removes a significant evaluation barrier. You can now test whether GHAS findings justify the upgrade cost in your specific codebase - without needing to move to Enterprise or schedule a sales call. The self-serve model makes security tooling accessible to teams who previously couldn't trial it easily.</p>
